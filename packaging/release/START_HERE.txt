Tomba! Recompiled - v0.19.0-alpha

This package does not include the game.

Select your verified North American Tomba! disc image (SCUS-94236) in the
launcher. CUE/BIN, BIN, IMG, ISO, Steam CAR, and CHD are supported. Steam's
t_data_u.car can be selected without renaming it. OpenBIOS is included; a Sony
BIOS is optional and is not distributed with this project.

Seamless Loading is enabled by default. On first launch, it prepares about
71 MiB of decoded data from your disc and caches it for later launches. The
game runs at normal speed, including audio. No compiler, Python or Generate
step is needed. Keep your disc available for movies and other original data.
Disable Seamless Loading on the Mods page to restore retail loading. If you
previously enabled Fast Loading, disable it before using Seamless Loading.
Stock SCUS-94236 assets are required; asset replacement mods are unsupported.
HD Texture Packs changes host-rendered artwork only and remains compatible
with the stock disc data used by Seamless Loading.
Whole-game transition coverage is still under test.

Other bundled mods are disabled by default. Configure them from the Mods page.
Custom Renderer defaults to Fit to Window (uncapped), with fixed 16:9, 21:9
and 32:9 choices. Leave it disabled for stock 4:3 rendering.
Quick-save states from v0.18.0 and earlier do not load in this version; they
are refused safely. Memory cards carry over, so save in-game before updating.

HD Texture Packs is disabled by default. Enable it in Mods, use Open folder
to install compatible PNG/JPEG/WebP images, and select OpenGL to display
replacements. Dump textures collects native source usage while playing; exit
the game to finish capture PNGs in dumps. Read docs/HD_TEXTURE_PACKS.md
for setup and editing, and docs/DUCKSTATION_TEXTURE_FORMAT.md for exact support.
The separate optional Tomba-HD-texture-example.zip provides five synthetic
checkerboards and a Tomba-specific README; no game artwork is included.

Linux AppImage state is stored in:
  ${XDG_DATA_HOME:-$HOME/.local/share}/TombaRecomp

Set TOMBA_RECOMP_DATA_DIR before launch to choose a different writable root.
